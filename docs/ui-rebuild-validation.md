## PT-Gen 实际联调补充（2026-10-22）

用户反馈补充失败后，检查发现配置指向 pt-gen-universal 的网页根路径。该服务收到 `url` 参数后返回 302 到 `/api/v1/info`，原客户端未跟随重定向。已通过现有设置接口改为完整 API 地址，保留原密钥；客户端增加同源重定向兼容，跨站重定向不会继续携带请求。

携带现有服务密钥的实际请求可以成功访问，豆瓣搜索成功；豆瓣 `1292052` 简介返回成功、694 字符。IMDb `tt12879782` 及另一 IMDb 条目均返回 PT-Gen 的 `JSON-LD script not found`；PT-Gen 容器直连前者得到 HTTP 202、0 字节内容。这属于独立 PT-Gen 的上游抓取失败，没有修改或重启该容器。

应用现在区分凭据错误、API 路径错误、超时、非 JSON 返回和 IMDb 解析失败，不再把它们全部归为参数问题。新增 5 个重定向、错误分类及密钥保护测试；相关资料测试 7 项通过，另验证发布资料浏览器流程。

修复上线后通过应用自身 `/api/media/ptgen` 再次实测：豆瓣简介成功返回 694 字符；IMDb 请求明确显示 JSON-LD 解析失败。验证未保存影视资料或修改任何发布草稿，其他服务配置与密钥未变。


## PT-Gen 片名搜索与 IMDb 失败恢复（2026-10-22）

- 问题：发布资料原先优先 TMDB → IMDb → PT-Gen；当前部署的 IMDb 网页抓取无法获得 JSON-LD，新增 `IMDB_API_KEY` 也不会被该抓取器使用。本次修复应用的资料来源选择和失败恢复，不宣称修复了上游 IMDb 抓取器。
- 发布资料现在默认 PT-Gen 豆瓣片名搜索；核对年份、季度后获取所选条目详情。保留 TMDB 搜索/详情和手动链接补充；共享选片器供批量重命名调用时仍默认 TMDB。
- 失败后提供“按片名查找豆瓣”。不自动采用首项，不自动采用关联 IMDb 条目；关联链接继续展示供核对。缺失的上游字段不会清空已有海报、名称等资料。
- 人工修改与重新获取冲突时预览；忽略已过期的搜索/选片响应，并保留失败前的资料。修改资源或字段后，待确认的旧补充结果也不能覆盖新内容。
