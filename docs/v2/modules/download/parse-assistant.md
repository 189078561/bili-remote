# 解析助手

Chrome 和 Edge 使用同一个 Manifest V3 扩展。在 B站下载的「解析助手 · 本机 Web」面板下载扩展安装包。解压后用浏览器扩展管理页的「加载已解压的扩展程序」安装。

在扩展设置添加项目的网页地址和自定义名称。在目标项目网页保持登录，添加时授权扩展访问该站点。每次操作只发送到当前目标项目。普通视频支持分 P。番剧只从 B 站的正片分区读取集数，并使用浏览器登录状态读取完整 Web DASH 档位。

- 「推送解析列表到项目」向 `POST /api/parse-assistant/imports` 发送全剧正片和档位，用户可在项目页面独立选择。列表在当前服务进程内保留最多四小时，重启后需重新推送。
- 「推送下载」向 `POST /api/parse-assistant/jobs` 提交所选视频和音轨。项目端则通过 `POST /api/parse-assistant/imports/{id}/jobs` 入队。
- 示例选择体为 `{"choices":[{"episode":0,"video":0,"audio":0}]}`。三个索引对应当次解析结果，选择固定轨道。
- 所有写入使用 Bili Remote 会话与 CSRF 校验。扩展只传播放轨道，不传 B 站 Cookie。作业运行依赖 VPS 可以读取 B 站 CDN，播放地址过期后在扩展重新推送。

生产装配使用现有 API 注册、命名计划和下载队列，无新增数据库迁移。测试使用合成剧集、临时数据库和 Chromium 本地登录检查。
