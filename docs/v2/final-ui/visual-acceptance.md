## 对照方法

每个页面通过 Playwright 在真实 Chromium 中运行，按相同视口截图，并与对应设计图并排比较页面骨架、导航、字号、颜色、内容密度、间距、表格及控件排列。除人眼截图外，测试还以程序断言固定了关键几何与语义：五入口导航节点位置（桌面顶栏、手机安全区底栏）、页面无横向溢出、选中后上下文条出现且无禁用按钮、详情面板宽度、预览面板宽度、浅色/深色背景精确值（`rgb(245,245,241)` / `rgb(22,29,26)`）。

## 各页对照结论

### 首页（01-home）

对齐：顶部横向五入口；主体为最近资源主列与任务/最近产物辅助列，取消大面积宣传文案；快捷操作（打开文件、新建下载、继续处理）为真实入口。空态显示“还没有”而不是示例影视作品；任务进度与错误重试来自真实 jobs/tasks 投影。手机端任务优先、资源列表、底部五入口。

差异：设计图示例影视作品与海报为演示内容，实际页面显示合成空态或真实临时目录资源；这是数据差异，不是组件形态差异。

### 文件管理（02-files）

对齐：轻量目录导航 + 宽敞文件列表；未选择时批量条隐藏，选择后出现“进入工作台 / 命名 / 更多”；文件行显示类型图标、文件名、媒体摘要、大小、时间、选择状态、更多操作；行“更多”内按需打开详情，Escape 关闭。手机端目录抽屉，单列列表，详情全屏宽度 390。测试断言批量条在选中后无可见禁用按钮，未选择时隐藏。

差异：设计图演示文件名、容量、时间为占位；实际页面显示合成测试文件与真实修改时间。

### B站下载（03-download）

对齐：线路/链接行、阶段反馈（未解析、解析中、解析成功、失败）、媒体摘要、逐集真实画质、统一画质与逐集调整、下载摘要；手机端单列选集，底部操作区高于安全区导航。下载任务展示进度/速度/状态/取消/重试/错误详情；完成后打开文件管理或进入工作台。空态、解析失败、120 集、任务状态均有截图。

差异：设计图演示视频封面与下载速度非生产数据；实际页面以离线解析结果与合成任务呈现，离线下载核心未改动。

### 设置（04-settings）

对齐：桌面分类导航 + 右侧紧凑行内设置；手机分类选择 + 同一设置面；仅在有修改时显示保存栏；目录值编辑显示“待校验”；凭据不回显；真实配置搜索跳转并展开对应项。分类覆盖目录、B站下载、命名规则、副标题模板、截图报告、图床种子、TMDB/Bangumi/PT-Gen、日志系统。

差异：无。所有设置项均为真实 schema，保存经 `GET/PUT /api/settings`，不生成静态表单。

### 发种工作台（05-workbench）

对齐：单资源工作区；顶部资源摘要（名称、路径、数量、季集、分辨率/编码、资料状态、更换资源、完整预览）；影视匹配结果与更换匹配面板；命名与原/目标名差异、变更总数、规则与逐集调整；发布三字段（主标题/副标题/简介）直接编辑并实时同步、单独复制、人工编辑保护；缩略图/媒体报告/种子制作三个工具按需展开，采用参数→执行→真实产物→结果操作；完整预览按需打开。手机端同顺序，工具与预览全屏。

差异：设计图示例匹配状态与种子信息为演示；实际页面使用离线元数据、真 FFmpeg 截图、真 MediaInfo、真本地制种，本地缩略图在上传图床前标注“待上传”并排除出可复制内容。

## 视觉差异清单（已处置）

以下差异在对照中发现并已在 `codex/final-ui-v2` 提交中处理，不构成未完成项：

- 旧版左侧全局导航已替换为同一五入口节点的桌面顶栏与手机底栏，不再保留折叠抽屉。
- 旧版三栏工作台已替换为单资源工作区；常驻文件浏览器与重复发布预览取消。
- 文件管理常驻详情改为行“更多”按需打开；无意义禁用按钮已消除，批量操作随选择状态出现。
- 首页统计卡片大屏模式取消，改为真实资源/任务/产物列表。
- 320px 宽度下旧文件时间列溢出已通过移动端断点隐藏解决。

## 结论

五个页面的导航方式、信息架构、组件形态、内容密度与语义颜色均与五张设计图一致；桌面 1440×900、手机 390×844 及补充尺寸、浅色/深色、空数据、长内容、失败状态均通过真实浏览器对照与程序断言。剩余差异仅为设计图演示内容与真实数据/空态的差异，符合“演示内容不得写入正式页面”的约束。
