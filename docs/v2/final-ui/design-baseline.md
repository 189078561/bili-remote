## 固定设计变量

背景 #f5f5f1；内容面 #ffffff；主要文字 #23342f；辅助文字 #6e7b74；分隔 #e0e5de；辅助面 #f1f4ef；主操作 #2e6653；选择面 #e7f0e8；警告 #95621e / #fbf1dd；错误 #ac4d3e / #fcf0ec。沿用已评审深色对应值。桌面顶栏68px；手机56px、底栏含安全区；页面横向留白48px（文件32px），手机17px；基础14px、主标题27/23px、分区18/16px；控件圆角6–8px、本地Lucide图标约19px。

业务实际数据长度、缺图、缺参数时允许自然换行和真实空状态；不允许更换主色、导航方式或页面信息架构。低频原有能力收纳到相同设计语言的菜单/面板，不能删除。

## 阶段门槛

0 锁定基线；1 外壳与Design System；2 FileBrowser；3 Workbench；4 下载；5 首页和设置；6 工具与边界状态；7 全量与视觉对照。每阶段独立提交。页面阶段必须先真实浏览器检查对应1440×900和390×844，再记录剩余差异；测试通过不代表视觉通过。

所有运行数据仅用临时目录或本工作区 `.dev/`；真实服务仅本机回环随机端口，不占8111。无生产配置/媒体/凭据/数据库；外部传输离线测试与在线缺口分开。最终不部署、不推送、不合并。
