## 设计交互规则

- 首页的资源动作直接进入该资源的工作台；任务项可展开进度和日志。无需先进入一个宣传入口页。
- 文件选择前只显示搜索/排序/创建入口。选中后用上下文条替换普通工具条，出现适用的进入工作台、命名与更多操作；没有无意义的灰色按钮。更多操作区分复制/移动/删除，冲突页不提供隐式覆盖。
- 下载“解析成功”先确认作品/分P范围；“选集画质”显示每项可用规格和共同选择。运行状态显示分集进度、速度与具体任务；失败状态给原因及重试/登录入口；完成以实际产物入口为主。
- 设置仅编辑现有 schema、规则仓库或已有工具配置：可直接切换的用小控件，长文本/目录/敏感连接按需展开。修改后出现本分类保存栏，不改变其他分类/活动任务。敏感值只有未配置/已配置状态，原型不含凭据。配置映射见 `settings-map.md`。
- 工作台影视匹配完成后显示紧凑身份条；重新匹配才展开候选。命名默认展示前后结果与缺项，展开查看逐文件差异；执行仍须真实安全预览和明确确认。主/副标题与简介直接编辑，人工内容不被刷新覆盖。
- 工具不是另一个常驻工作区；执行中/完成结果都跟随当前资源，完成后可加入预览。完整预览提供格式、效果/源码切换和复制；不出现保存项目或发布草稿。
