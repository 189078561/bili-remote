# 最终 UI 设计系统

五个一级页面：首页、文件管理、发种工作台、B站下载、设置。任务与通知为全局抽屉；资源选择、命名详情、辅助工具及发布预览为上下文面板。兼容入口保留，V2 不再使用旧工作台三栏 DOM。

## 视觉与组件

采用原生 HTML/CSS/JS，不增加框架依赖。全局中文系统字体、14px 正文、12–13px 辅助说明、24px 页面标题；工作台内采用连续内容区与轻量分隔线。控件通常 38–40px，移动端至少 44px。单一资源摘要、紧凑候选列表、文件名对照、宽发布编辑区是视觉主体。

工作台与共享 FileBrowser 的局部 `--ws-*` 变量兼容独立入口；主应用共享语义色。顶栏主题按钮在系统、浅色、深色之间切换，唯一新增浏览器持久偏好是 `bili-theme`。所有五页、任务抽屉、设置及表单均需检查深色对比度。

图标使用本地 Lucide 风格 SVG sprite，ISC 许可证随源码保留，无 CDN 或混用图标字体。图标按钮均有名称，装饰图标对辅助技术隐藏。

## 页面布局

- 首页：轻量操作入口、下载根目录最近视频/目录、实际当前任务。空数据解释下一步；读取失败明确说明；没有磁盘 API 时不显示虚构容量。
- 工作台：当前资源 → 默认可见影视搜索 → 紧凑命名调整/对照 → 三字段发布编辑 → 缩略图/报告/种子工具。预览采用桌面宽面板与手机全屏；编辑节点与资源上下文保持同一实例。
- 文件管理：目录导航、文件列表、按需详情。操作随选择数量变化；低频操作放更多菜单，图片/文本只使用真实可读接口。
- 下载：先解析链接，再选择内容与画质，然后队列。高级命名与保存路径默认折叠，画质始终直接可见。已完成任务有工作台与文件管理入口。
- 设置：分类导航及真实字段。V2 全局规则通过规则 API 独立保存；旧兼容命名预设仍可管理，不改变已存在配置键。

## 响应与可访问性

验收尺寸为 1440×900、1280×800、1024×768、768×1024、390×844，分别检查浅色和深色。900px 以下主导航转为抽屉，设置使用分类选择；下载选集与操作按钮适应触屏；工作台工具和预览使用覆盖面板。长路径与错误可换行，不依靠隐藏页面溢出来掩盖布局问题。

任务抽屉及工作台面板有 Escape、焦点约束及关闭后焦点恢复。任务抽屉打开后背景不可交互；嵌套安全确认仍使用既有弹窗。通知保留真实失败原因，未知进度使用不定进度，不能显示虚假完成。
