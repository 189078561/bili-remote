## 已执行的离线验证

- B站普通视频、分P、番剧、合集、单集/多集格式和批次任务通过既有 API 契约测试。
- 下载完成后真实隔离文件进入文件管理，任务路径与后续工作台资源一致。
- metadata provider 使用明确命名的离线测试替身，返回候选后由真实工作台解析、人工确认并进入命名。
- 图床上传使用离线 transport 验证任务记录和错误形态，不产生可传播的公网链接。
- qBittorrent 使用 mock transport 校验真实 API 形态，不连接任何真实客户端。
- BDInfo 缺失或被禁用时明确返回不可用，不生成伪造报告。

这些结果只能证明页面状态机、服务边界和错误显示，不证明第三方认证、额度、限流、返回结构或网络稳定性。

## 在线验收步骤

1. 在隔离预发布环境由有权限人员注入外部测试凭据；不得写入 Git、报告或终端日志。
2. B站使用授权账号分别验证 Web/TV 登录、普通视频、分P、番剧和合集，只下载明确允许的短测试资源。
3. 验证下载完成后的原始文件名、文件管理定位、工作台资源路径和重试/取消状态。
4. TMDB 和 Bangumi 分别搜索中英文及原名，选择候选后确认身份与季集传递。
5. 验证 PT-Gen 和 Minfo 的成功、超时、限流及不可用时的可编辑降级。
6. 上传受控测试图片并核对真实远端 URL、下载显示和失败重试。
7. 在独立 qBittorrent 实例导入已生成 torrent，只核对本地测试实例，不向真实 PT 站点发布。
8. 用合法蓝光样本执行 BDInfo，并人工比对报告内容。

## 安全与失败处理要求

- 凭据接口只返回“已配置”，不得回显密钥。
- 外部 401/403、限流、超时、5xx 和解析异常必须显示可理解错误，不覆盖当前人工编辑。
- 上传或导入失败不能删除本地真实产物。
- 下载失败不得留下被当作完成记录的资源。
- 在线联调只使用授权测试资源，不自动执行真实 PT 发种。
