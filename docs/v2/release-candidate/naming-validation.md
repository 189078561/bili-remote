## `Motion.Study.S01E01` 问题处置

此前截图中的目标名：

```text
Motion.Study.180p.WEB-DL.MPEG-4-HDVWEB.mp4
```

问题不在最终文件名渲染，而在模板选择：带明确 `S01E01` 文件名证据的资源曾使用了不含季集的电影回退模板，同时媒体编码文字也可能落到通用 MPEG-4 标签。

`f269c47` 将命名模板选择改为优先使用文件名季集证据。当前真实媒体测试确认：

- 规则来源返回 `filename_episode`，可在界面解释目标名为何使用剧集模板。
- `Motion.Study.S01E01.mp4` 的目标名包含 `.S01E01.`。
- `Motion.Study.S01E02.mp4` 的目标名包含 `.S01E02.`。
- 显式覆盖后的第三集目标名包含 `.S01E03.`。
- 规则来源不是通过界面文案硬编码，而是命名服务返回的有效规则 provenance。

`9b3ee6b` 进一步保护显式片源 `WEB-DL` 和制作组 `RELEASE`，确保自动探测或回退值不会覆盖用户明确输入。

## 规则来源

| 场景 | 规则来源 | 行为 |
| --- | --- | --- |
| 文件名包含 `S01E01` | `filename_episode` | 自动选择剧集模板 |
| 用户手动设置片源/制作组 | `manual` | 显式值保留在最终规则中 |
| 无季集证据的影片 | `movie_fallback` | 使用电影模板并显示缺集告警 |
| 无季集证据但用户选择剧集模板 | 显式剧集规则 | 未输入集号前不能安全执行；输入后使用人工集号 |

## 已执行用例

### 电影命名

合成文件 `unrecognized_source_file.mp4` 被明确识别为缺少季集证据。实际预览结果：

```text
Unrecognized.Source.2025.180p.WEB-DL.H.264.AAC-HDVWEB.mp4
```

页面和 API 同时暴露 `missing_episode`，提醒用户这是电影回退或需要手动补集号。

### 单集电视剧

带 `S01E01` 的文件采用剧集模板，目标名保留季集段。真实 ffprobe 提供分辨率、编码和音频参数；发布副标题服务不参与文件名生成。

### 整季批量命名

同一目录内三集视频、外挂 SRT 和 ASS 共生成 5 个预览操作。目录与子文件同时选择时按规范化路径去重，实际只处理 3 个视频和 2 个字幕文件。

### 集数手动覆盖

文件名中的 `S01E09` 经逐文件覆盖映射为第 3 集，目标名生成 `S01E03`，预览和执行结果一致。该用例证明人工值优先于文件名自动值，且覆盖只作用于当前操作。

### 英文名称、自定义名称和参数

- 人工选择标题生成英文目标片名。
- 片源 `WEB-DL`、制作组 `RELEASE` 作为显式规则保留。
- 分辨率、视频编码、音频编码来自 ffprobe，不从文件名猜测。
- 无法确认的参数显示缺失或使用可解释规则，不标记成探测事实。

### 冲突、预览和零写入

预览后对每个目标路径检查真实文件系统：

- 预览阶段源文件没有改写。
- 预置同名目标时预览返回 `target_exists` 且禁止执行。
- 移除冲突后预览重新生成新 token 和 revision。
- 确认执行后源文件移动到目标路径，每个目标文件与对应源文件逐字节一致。

### 撤销

完成重命名后通过命名详情发起撤销预览，再确认执行。所有原始路径恢复，所有文件逐字节等于执行前内容。工作台人工简介在改名和撤销后仍存在，证明文件变更不会覆盖当前人工发布内容。

### 长文件名

文件名长度超过 150 字符的剧集样本仍能生成剧集目标名，浏览器和 API 未发生截断或路径逃逸。移动端长文件名由页面换行/省略策略显示，横向溢出测试通过。

## 安全约束

- 执行改名必须经过预览 token、上下文 revision、确认标志和幂等键。
- 冲突、非法路径、源指纹变化或目标已存在时拒绝执行。
- 不自动覆盖、不静默移动文件。
- 撤销同样经过预览和确认。
- 规则记忆只保存可复用偏好，不保存发布正文或发种草稿。

## 已知边界

- 智能命名只使用可靠的文件名、用户输入和媒体探测事实。来源不明时保持可编辑，不猜测集号。
- 复杂多季映射、非常规动画集数和站点特定命名仍需真实样本补充。
- 撤销依赖持久审计记录；超过既有保留策略的历史批次是否可撤销，以当前数据库中的审计状态为准。
