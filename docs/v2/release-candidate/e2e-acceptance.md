日期：2026-11-11

## 完整链路

已执行并通过的主链路：

```text
离线下载进程写出真实视频
→ 完成下载并打开文件管理
→ 选中真实文件进入发种工作台
→ 离线影视 provider 返回候选并人工确认
→ 真实命名预览
→ 安全重命名
→ 人工编辑发布内容
→ FFmpeg 截图和拼接
→ MediaInfo 报告
→ 本地制作 torrent
→ 下载 .torrent
→ 完整发布预览与复制
→ 撤销重命名并恢复原名
```

替换边界只有两个：

- 下载器子进程由离线脚本把 FFmpeg 合成视频复制到任务目标。
- TMDB provider 使用离线候选，无法取得真实在线凭据。

以下部分均使用真实实现：FastAPI 应用、SQLite、worker、文件注册、文件安全、ResourceRef 传递、命名服务、ffprobe、FFmpeg、MediaInfo、torrent 服务、任务队列、浏览器 DOM 和下载接口。

## 人工预发布操作清单

1. 先在桌面完成一次普通视频和一次整季下载，再检查文件管理路径。
2. 从首页资源、文件选择和下载完成三种入口分别进入工作台。
3. 修改匹配结果、片源、制作组、集号和标题，观察预览来源和变更计数。
4. 故意制造目标冲突，确认不能执行；处理后预览并人工确认改名。
5. 生成缩略图、MediaInfo 和 torrent，下载每个真实产物并检查完整预览。
6. 撤销改名，确认发布正文和工具结果未被错误清空。
7. 在 390px 手机视图测试软键盘、长文件名、长简介和底部安全区。
8. 对任何外部服务失败记录具体状态，不得以页面按钮存在代替在线通过。
